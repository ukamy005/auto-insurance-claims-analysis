# Auto Insurance Claims Analysis & Performance Dashboard

## Project Overview
An independent data analytics project exploring how business intelligence tools can support insurance claims monitoring and operational decision-making.

I developed an interactive dashboard using Microsoft Power BI and a simulated dataset of 500 auto insurance claims.

## Tools Used
- Microsoft Power BI
- DAX
- Microsoft Excel

## Project Objectives
- Monitor insurance claims volume.
- Analyse total and average claim amounts.
- Calculate claim approval rates.
- Examine claims processing times.
- Compare claims across provinces, categories and submission channels.

## Technical Skills Demonstrated
- Data analysis
- Data visualisation
- DAX calculations
- Dashboard development
- Business intelligence
- Data interpretation

## Dataset
The project uses 500 simulated insurance claims created for educational and portfolio purposes. It does not contain actual Intact Financial Corporation data.

## Learning Outcomes
Developed practical experience creating Power BI measures, designing interactive reports and exploring how data can support business decisions.
